# UI 设计规范

布局参照 FinalShell 的主窗口结构，视觉使用暗色主题。**借鉴布局，不照抄样式。**

## 主窗口布局

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏：＋新建连接  连接管理  设置                 会话状态 ● │
├──────────────────────────────────────────────────────────────┤
│ 标签栏：[socat-248 ×] [campanula-248 ×] [+]                  │
├───────────────────┬──────────────────────────────────────────┤
│ 目标设备资源       │                                          │
│ IP / 运行时间/负载 │                 Shell                    │
│ CPU / 内存 / 交换  │              （xterm.js）                 │
│ 进程（可排序）     │                                          │
│ 网络 / 延迟曲线    │                                          │
│ 磁盘已用/总量      │                                          │
├───────────────────┼───────────────────┬──────────────────────┤
│ 远程目录树         │ 当前目录文件       │ 绝对路径（可复制）    │
│ /                 │ 名称 / 大小 / 操作 │ 上传进度             │
│ ├─ home           │                   │                      │
│ ├─ etc            │                   │                      │
│ └─ var            │                   │                      │
└───────────────────┴───────────────────┴──────────────────────┘
```

上方左侧是窄资源栏，右侧是 Shell；下方文件区常驻显示，左侧为从 `/` 开始的远程目录树，右侧为当前目录文件，不提供手动隐藏 SFTP 的开关。

桌面窗口默认宽 1200，高度为主屏幕逻辑高度的 80%；无法获取主屏幕信息时回退为 760。最小尺寸为 760 × 480，启动后仍可手动调整。

## 区域职责与交互

- **工具栏**：新建 SSH 连接、打开连接管理器、传输进度弹层和会话状态灯；“日志”左侧显示本机默认下载目录的完整路径，初始为系统用户目录下的 `Downloads`；点击路径会在 Finder 中打开该目录，点击“更改”通过 macOS 原生选择器更换目录并持久化，普通文件和文件夹统一下载到所选目录。连接管理器固定高 600px（小窗口保留 40px 纵向边距），头部与工具栏固定，连接列表内部纵向滚动；搜索框按名称、主机 IP 或用户名实时过滤，搜索时隐藏空分组。连接管理器支持文件夹分组、自定义名称/备注、密码或多私钥认证，新连接自动载入默认私钥，主机和用户名保持空白且不显示示例 IP 或默认用户名提示；自定义连接右键可编辑，文件夹右键可在该分组下添加连接。
- **标签栏**：每个标签页对应一条独立 SSH 会话；可关闭、可拖拽排序；`+` 打开连接选择器；关闭标签才显式销毁会话。
- **终端区**：切换标签只隐藏视图，不销毁 xterm 实例；远程断线和重连期间保留已经渲染的内容，断开时禁用输入且不排队。Cmd+C 复制选区、Cmd+V 粘贴剪贴板，事件显式阻止默认行为和传播，避免 WebView 弹出系统 Paste 菜单；粘贴仍走 bracketed paste。
- **资源栏**：显示目标 IP（可复制）、运行时间、负载、CPU、内存、交换、进程、网络、延迟和磁盘。
  - 进程列为内存、CPU、命令及对应比例条带；点击 CPU 或内存表头在升序/降序之间切换。
  - 网络默认自动选择当前活动网卡，也可手动切换；网络图高度固定，中间为零轴，红色上行柱向上、绿色下行柱向下，柱宽固定为 3px、步长固定为 5px，上下共用速率刻度且不再重叠；延迟显示本机到目标设备的 ping 曲线。
  - 磁盘每行显示路径、已用/总大小和已用比例条形图。
  - 点击“系统信息”打开详细弹窗，展示主机名、操作系统、内核版本、架构、CPU 型号和逻辑核数。
  - 所有下拉框使用应用内暗色自定义组件，不使用系统原生弹层；连接入口位于工具栏最左侧，以打开文件夹图标展示连接菜单。
  - 每 1 秒刷新一次，仅在当前标签已连接时采集；图表使用 Canvas，不使用高频 DOM 动画。
- **日志**：右上角“日志”可查看后端连接/错误日志和界面事件，前后端均只保留最近 3 天。
- **未知主机**：使用应用内弹窗确认指纹，用户信任后写入 known_hosts；指纹变化仍拒绝。
- **连接删除与标签关闭**：自定义连接永久删除，OpenSSH 连接仅从应用列表隐藏且不修改原配置；所有删除均使用应用内确认弹窗，不依赖系统 `confirm()`。关闭标签立即释放 UI，再异步清理后端会话，不被终端销毁异常阻断。
- **远程目录树**：根节点为 `/`，目录按需展开，不一次性遍历整台机器；单击目录更新右侧当前路径。
- **当前目录文件**：使用规范化绝对路径，路径栏可复制；双击目录进入，双击文件进入缓存编辑；工具栏提供刷新、上级目录、下载选中文件/文件夹和上传。选中文件夹后通过 SFTP 递归下载到本机默认下载目录，保留目录结构、空目录和普通文件权限，同名目录自动加序号，符号链接不跟随。Bash/Zsh 中 `cd` 后通过提示符路径通知自动跳转，控制序列和启动时的初始化脚本均不显示在终端中；Windows cmd.exe 暂不支持联动。
- **缓存编辑**：文件先流式下载到本地私有缓存，双击使用默认应用，右键可选择其他 macOS 应用打开；新选择会持久化为后续默认打开方式，直到再次更改。VSCode 等编辑器保存后自动回传原远程路径，并显示成功/失败通知。
- **传输中心**：右上角按钮展示上传/下载进度、完成和失败状态，可清除已完成任务；运行中显示当前远程文件路径，文件夹任务显示递归文件的总字节数和总进度。
- **拖入上传**：支持从 Finder 拖文件到当前目录列表上传；不做拖出到 Finder。
- **分栏**：后续可拖拽调整资源栏、目录树和文件区高度/宽度；首版使用固定比例。

## 暗色主题色板

| 用途 | 色值 |
|---|---|
| 窗口背景 | `#0F1115` |
| 面板/卡片背景 | `#16181D` |
| 边框/分隔线 | `#262A31` |
| 主文本 | `#E6E8EB` |
| 次要文本 | `#9AA3AF` |
| 强调色（按钮/选中） | `#4C8DFF` |
| 成功/已连接 | `#3FB950` |
| 警告/重连中 | `#D29922` |
| 错误/断开 | `#F85149` |

### 终端配色

- 背景 `#0B0E12`，前景 `#D7DCE2`，光标 `#4C8DFF`，选区 `rgba(76,141,255,0.25)`
- ANSI 标准色适度提亮以适配深色背景（红 `#FF7B72`、绿 `#7EE787`、黄 `#F2CC60`、蓝 `#79C0FF`、品红 `#D2A8FF`、青 `#76E3EA`）

## 字体与间距

- 终端：等宽字体优先 `JetBrains Mono`，回退 `SF Mono`、`Menlo`；默认 13px / 行高 1.35
- UI：系统字体（-apple-system），正文 12–13px
- 间距以 8px 为栅格（4/8/12/16），面板内边距 12px
- 滚动条：细窄（6px）、半透明，仅在滚动时显现

## 实现提示

- 用 CSS Grid 划分四个常驻区域，终端尺寸变化继续通过 ResizeObserver 上报。
- 所有颜色收敛为 CSS 变量（`--bg-window`、`--bg-panel` 等），为以后浅色主题留口。
- 标签页顺序可持久化到 localStorage；不持久化终端输出，也不据此恢复远程会话。
