# UI 设计规范

布局参照 FinalShell 的主窗口结构，视觉使用暗色主题。**借鉴布局，不照抄样式。**

## 主窗口布局

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏：＋新建连接  连接管理  设置                 会话状态 ● │
├──────────────────────────────────────────────────────────────┤
│ 标签栏：[socat-248 ×] [campanula-248 ×] [+]                  │
├───────────────────┬──────────────────────────────────────────┤
│ 目标设备资源       │                                          │
│ IP / 运行时间/负载 │                 Shell                    │
│ CPU / 内存 / 交换  │              （xterm.js）                 │
│ 进程（可排序）     ├───────────────────┬──────────────────────┤
│ 网络 / 延迟曲线    │ 远程目录树         │ 当前目录文件          │
│ 磁盘已用/总量      │ /                 │ 绝对路径 / 上传下载   │
│                   │ ├─ home           │ 名称 / 大小 / 操作    │
│                   │ ├─ etc            │                      │
│                   │ └─ var            │                      │
└───────────────────┴───────────────────┴──────────────────────┘
```

左侧资源栏贯穿整个窗口高度；右侧上方是 Shell，下方文件区常驻显示，文件区左侧为从 `/` 开始的远程目录树，右侧为当前目录文件，不提供手动隐藏 SFTP 的开关。

桌面窗口默认宽 1200，高度为主屏幕逻辑高度的 90%；无法获取主屏幕信息时回退为 760。最小尺寸为 760 × 480，启动后仍可手动调整。

## 区域职责与交互

- **工具栏**：新建 SSH 连接、打开连接管理器、传输进度弹层和会话状态灯；“日志”左侧显示本机默认下载目录的完整路径，初始为系统用户目录下的 `Downloads`；点击路径会在 Finder 中打开该目录，点击“更改”通过 macOS 原生选择器更换目录并持久化，普通文件和文件夹统一下载到所选目录。连接管理器固定高 600px（小窗口保留 40px 纵向边距），头部与工具栏固定，连接列表内部纵向滚动；搜索框按名称、主机 IP 或用户名实时过滤，搜索时隐藏空分组。连接管理器支持文件夹分组、自定义名称/备注、密码或多私钥认证，新连接自动载入默认私钥，主机和用户名保持空白且不显示示例 IP 或默认用户名提示；新建和编辑统一使用“编辑连接”页面，自定义连接右键可编辑，文件夹右键可在该分组下添加连接。快捷键映射统一在应用设置和 Session 设置中维护，不与连接认证信息混合。
- **标签栏**：点击连接后立即显示连接中标签，SSH 成功后再绑定后端 `sessionId`；失败也保留标签并显示红点，右键可重新连接。已断开的会话右键“重连”调用后端重连，成功恢复绿点。每个标签页对应一条独立 SSH 会话；标签右键“复制标签页”使用相同连接配置创建新 Session，并紧挨原标签插入右侧；“会话设置”可独立修改当前 Session 的快捷键，并通过“同步全局配置”显式恢复全局值；`+` 打开连接选择器；关闭标签才显式销毁会话。标签可拖拽改变顺序，溢出时显示横向滚动条，按住 Shift 拖动空白区域也可横向滚动。全局禁用 WebView 原生右键 Reload，应用内文件、连接和标签菜单仍可用。
- **应用设置**：macOS 的 Tindomiel 应用菜单在 About 下方提供“设置…”及 `Cmd+,`，左侧资源栏底部也固定显示小齿轮入口，均打开同一个应用内设置弹窗；资源列表在齿轮上方独立滚动。齿轮右侧显示本应用 CPU 和内存合计，统计主进程、Go 后端与 WebKit 辅助进程，每秒更新，窗口隐藏时也持续采样，悬停可查看进程数。终端配色内建 Homebrew（黑绿，默认）、macOS ClearDark 和原自定义 Boring，保存后立即切换现有和新建终端的色板。终端字号默认 13px，可在 10–24 之间调整；回滚行数默认 10000，可在 1000–50000 之间调整；光标闪烁可关闭以减少空闲绘制。设置页也可选择下载目录，保存后立即作用于现有和新建终端，并在重启后保留。全局快捷键只在新 Session 创建时复制，已有 Session 不实时继承；Session 内的添加、删除和同步均不影响其他 Session 或全局配置。
- **终端区**：切换标签只隐藏视图，不销毁 xterm 实例，也不暂停 SSH/WS 流；隐藏期间输出继续写入 xterm 缓冲区，切回时显式滚动到底部。标签连续隐藏 30 秒后释放 WebGL，隐藏期间不创建 DOM 渲染器，快速切换不重建；再次激活时恢复 WebGL，可见终端恢复失败才使用普通渲染回退，终端缓冲区、输出和设置保持不变。scrollback 默认 10000 行，超出后按终端常规行为淘汰旧行。终端容器和 xterm screen 限制横向溢出，并监听内部滚动事件仅清零 `scrollLeft`，中文输入法辅助层不会把整个工作区或 Windows ConPTY TUI 推偏，纵向 scrollback 与组合输入保持可用。远程断线和重连期间保留已经渲染的内容，断开时禁用输入且不排队。Cmd+C 复制选区；Cmd+V 直接使用原生 `paste` 事件中的剪贴板文本，阻止默认行为和重复传播，避免 WebView 弹出系统 Paste 菜单及剪贴板读取权限请求；粘贴仍走 bracketed paste。
- **资源栏**：显示目标 IP（可复制）、运行时间、负载、CPU、内存、交换、进程、网络、延迟和磁盘。
  - 进程列为内存、CPU、命令及对应比例条带；点击 CPU 或内存表头在升序/降序之间切换。
  - 网络默认自动选择当前活动网卡并保持选择，网卡消失或重新选择自动模式时才重新挑选，也可手动切换并立即刷新数字和图表；每个会话分别保存网卡最近 40 秒的连续时间轴、ping 历史和网卡选择，后台标签也持续按时间推进，切回不重新加载。后端通过独立 `network` 帧按一秒时间槽推送，同一秒的新样本覆盖旧值，缺失或超时秒补 0，迟到但仍在窗口内的样本按原时间戳回填；Linux/macOS 在延迟成功后按跨过的整数秒数求平均，Windows 直接采用系统每秒速率。每根柱严格表示一秒，从右往左第 n 条即 n 秒前，历史不做插值。每个 Session 的每张网卡分别根据窗口内上下行样本计算共用刻度，旧峰值超过 40 秒后，上传和下载柱一起按新刻度重绘，任一方向出现新高时也统一缩放。网络图高度固定，中间为零轴，红色上行柱向上、绿色下行柱向下，柱宽固定为 3px、步长固定为 5px；图下显示可见起止时刻，悬停柱子显示该秒时间及完整上下行速率；速率使用不换行的紧凑格式，完整网卡名在下拉和悬停中显示；延迟显示本机到目标设备的 ping 曲线。
  - 磁盘每行显示路径、已用/总大小和已用比例条形图。
  - 点击“系统信息”打开详细弹窗，展示主机名、操作系统、内核版本、架构、CPU 型号和逻辑核数。
  - 所有下拉框使用应用内暗色自定义组件，不使用系统原生弹层；连接入口位于工具栏最左侧，以打开文件夹图标展示连接菜单。
  - 每个会话后台持续采集，正常目标间隔为 1 秒，Windows 额外包含 CIM 采集耗时；前端保存各会话最近快照，切换标签直接展示，不影响远端采集。图表使用 Canvas，尺寸仅在初始化或分栏变化时读取；网络图不做全图插值动画，仅按采样结果和滚动刻度重绘。
- **日志**：右上角“日志”可查看后端连接/错误日志和界面事件，分别写入 `tindomiel.log` 与 `frontend.log`，单文件达到 4 MiB 后轮转，备份均保留最近 3 天。
- **未知主机**：使用应用内弹窗确认指纹，用户信任后写入 known_hosts；指纹变化仍拒绝。
- **连接删除与标签关闭**：自定义连接永久删除，OpenSSH 连接仅从应用列表隐藏且不修改原配置；所有删除均使用应用内确认弹窗，不依赖系统 `confirm()`。关闭标签立即释放 UI，再异步清理后端会话，不被终端销毁异常阻断。
- **远程目录树**：根节点为 `/`，首次只读取根目录，点击箭头才读取该目录的子节点，不一次性遍历整台机器；未加载目录灰显，加载期间显示“读取中”。单击目录名只更新右侧当前路径，路径联动不自动展开或读取祖先目录。刷新仅重新读取根目录和用户已展开节点。每个会话以独立 Map 保存节点、展开状态和当前路径；后台请求完成后写回原会话，切换时直接恢复，不重新读取，也不污染其他会话。
- **当前目录文件**：使用规范化绝对路径，路径栏可复制；双击目录进入，双击文件进入缓存编辑；工具栏提供刷新、上级目录、下载选中文件/文件夹和上传，工具栏过窄时可横向滚动。文件列表按会话缓存当前路径、内容和加载状态，只有手动刷新、进入目录、路径联动或上传完成后才重新读取；切换标签不重新请求，后台完成的结果写回原会话，切回时直接恢复。初始为目录优先、名称升序，点击“文件名”“最近修改”或“创建时间”切换排序；表头依次为文件名、大小、最近修改、创建时间、权限，单元格右边界显示浅灰竖线作为列宽拖拽手柄，悬停和拖拽时加粗提亮，标题与文件行统一行高并垂直居中。创建时间由后端批量查询远程系统，不支持时显示 `—`。选中文件夹后通过 SFTP 递归下载到本机默认下载目录，保留目录结构、空目录和普通文件权限，同名目录自动加序号，符号链接不跟随。Bash/Zsh 中 `cd` 后通过提示符路径通知自动跳转，控制序列和启动时的初始化脚本均不显示在终端中；Windows cmd.exe 暂不支持联动。
- **缓存编辑**：文件先流式下载到本地私有缓存，双击使用默认应用，右键可选择其他 macOS 应用打开；新选择会持久化为后续默认打开方式，直到再次更改。VSCode 等编辑器保存后自动回传原远程路径，并显示成功/失败通知。
- **传输中心**：右上角按钮展示上传/下载进度、完成和失败状态，可清除已完成任务；运行中显示当前远程文件路径，文件夹任务显示递归文件的总字节数和总进度。
- **拖入上传**：支持从 Finder 拖文件到当前目录列表上传；不做拖出到 Finder。
- **分栏**：资源栏宽度、文件区高度、目录树宽度均可通过分隔条拖拽调整；文件表头各列宽独立拖拽，终端尺寸变化通过 ResizeObserver 同步远程 PTY。

| 用途 | 色值 |

| 窗口背景 | `#0F1115` |
| 面板/卡片背景 | `#16181D` |

### 终端配色

- **Homebrew（默认）**：背景 `#000000`，前景 `#28FE14`，光标 `#38FE27`，选区 `rgba(9,0,233,0.65)`；普通和粗体 ANSI 绿色均为 `#28FE14`。基础色值来自 macOS Terminal 内建 Homebrew。
- **ClearDark**：背景 `#191D27`，前景/光标 `#E0E0E0`，选区 `#273D4C`；完整 16 色 ANSI 色板来自 macOS Terminal 内建 Clear Dark，不引入背景模糊绘制。
- **Boring（原自定义配色）**：背景 `#0B0E12`，前景 `#D7DCE2`，光标 `#4C8DFF`，选区 `rgba(76,141,255,0.25)`；ANSI 红 `#FF7B72`、绿 `#7EE787`、黄 `#F2CC60`、蓝 `#79C0FF`、品红 `#D2A8FF`、青 `#76E3EA`。

## 字体与间距

- 终端：等宽字体优先 `JetBrains Mono`，回退 `SF Mono`、`Menlo`；默认 13px / 行高 1.35
- UI：系统字体（-apple-system），正文 12–13px
- 间距以 8px 为栅格（4/8/12/16），面板内边距 12px
- 滚动条：细窄（6px）、半透明，仅在滚动时显现

## 实现提示

- 用 CSS Grid 划分四个常驻区域，终端尺寸变化继续通过 ResizeObserver 上报。
- 所有颜色收敛为 CSS 变量（`--bg-window`、`--bg-panel` 等），为以后浅色主题留口。
- 标签页顺序可持久化到 localStorage；不持久化终端输出，也不据此恢复远程会话。
